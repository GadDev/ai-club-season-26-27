# AI Club Season 2026–27 — Reference Curriculum Pack

This pack implements nine complete October→June reference curricula for the future adaptive voting system. It intentionally normalizes topic definitions into a canonical catalogue and keeps programme files focused on *placement, progression, monthly coherence, and voting logic*.

## 2026 calibration: durable vs current vs experimental

The curricula distinguish durable engineering ideas from current ecosystem practices. Context engineering is treated as a durable discipline; MCP, A2A, coding-agent harnesses, loop engineering, and some forms of long-running autonomy are tagged as current or experimental where appropriate. This protects the season from becoming a 2026 product catalogue.

Current-practice calibration used during design included official/primary material on context engineering, MCP's 2026 specification, A2A, agent SDK/runtime patterns, trace-based agent evaluation, and loop engineering. The curriculum remains vendor-neutral: products are examples, not learning outcomes.

## Data-model note

`topics.json` is intentionally close to what the voting application will eventually need: stable IDs, dependencies, related/follow-up links, programme/month appearances, curriculum/voting status, durability, and rough scoring metadata. `placements.json` separates canonical content from where that content appears—a useful distinction once voting begins to rearrange the season.
