# Support

This repository is maintained as the public programme and website for **AI Club · Season 2026–2027**. It does not provide a commercial support SLA.

## Where to ask for help

Use GitHub Issues for:

- reproducible website bugs;
- accessibility problems;
- broken links or incorrect public programme data;
- feature proposals;
- suggestions for AI Club sessions or workshops.

Before opening an issue, search existing issues and read [`CONTRIBUTING.md`](CONTRIBUTING.md).

For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead of opening a normal public issue.

## What to include

For a software problem, provide the page or route, browser/device information, reproduction steps, expected behaviour, and screenshots when useful.

For programme/content corrections, identify the affected session or page and provide a verifiable source when the correction concerns dates, speakers, venues, or other factual details.
